# dsa-pattern-toolkit
A collection of classical coding patterns with examples, reusable templates, and detailed explanations.  
This repo is designed to help recognize recurring problem-solving strategies in LeetCode and interview questions, and to build a personal library of solutions you can adapt quickly.

## Why this repo ?
Most coding problems fall into a handful of repeatable patterns. By mastering these, you can:
- Solve problems faster by recognizing the underlying structure.
- Reuse classical code templates with slight modifications.
- Prepare effectively for technical interviews and competitive programming.

## 8 Patters includes :
- Sliding Window
- Subset patterns
- Modified Binary Search
- Top K elements
- Binary Tree DFS
- Topological sort
- Binary Tree BFS
- Two Pointer
